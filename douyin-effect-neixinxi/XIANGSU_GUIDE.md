# 像塑复刻指南 · 内心戏泄漏器

本指南对应 `assets/` 下全部 PNG。在 **抖音像塑（普通版即可）** 按下列步骤即可复刻核心玩法。

## 1. 新建项目

1. 打开像塑 → **新建特效** → 选择 **2D / 人脸贴纸** 类模板  
2. 建议分辨率保持默认竖屏预览  
3. 把本包 `assets/` 里的 PNG 全部导入「资源管理」

## 2. 图层摆放

| 图层名（务必改名） | 素材 | 绑定 | 初始可见 |
| --- | --- | --- | --- |
| `badge_calm` | badge_calm.png | 人脸跟踪 · 额头上方 | ✅ 显示 |
| `thought` | sticker_thought.png | 人脸跟踪 · 头顶偏右 | ✅ 显示 |
| `badge_leak` | badge_leak.png | 人脸跟踪 · 额头上方 | ❌ 隐藏 |
| `badge_sos` | badge_sos.png | 人脸跟踪 · 额头上方 | ❌ 隐藏 |
| `badge_cute` | badge_cute.png | 人脸跟踪 · 额头上方 | ❌ 隐藏 |
| `sweat` | sticker_sweat.png | 人脸跟踪 · 右太阳穴 | ❌ 隐藏 |
| `banner` | banner_warning.png | 前景贴纸 · 屏幕顶部 | ❌ 隐藏 |
| `dm_01` … `dm_12` | 对应弹幕 PNG | 前景贴纸 · 分散左右 | ❌ 隐藏 |

弹幕建议初始位置：左右屏外各放一半，大小约屏宽 55%~70%。

## 3. 事件面板（核心）

### 事件 A：张嘴 → 泄漏

1. **添加触发** → **表情触发** → **张嘴**  
2. 添加特效动作：  
   - `badge_calm` → **消失**  
   - `thought` → **消失**  
   - `badge_leak` → **出现**  
   - `sweat` → **出现**  
   - 任选 4~6 个 `dm_xx` → **出现**（可再加位移动画：从屏外飞到中间）

### 事件 B：闭嘴 → 恢复淡定

1. **添加触发** → **表情触发** → **闭嘴**（或张嘴结束 / 反向）  
2. 动作：  
   - 全部 `dm_xx`、`badge_leak`、`badge_sos`、`banner`、`sweat` → **消失**  
   - `badge_calm`、`thought` → **出现**

### 事件 C：大张嘴 / 持续张嘴 → 社死模式

1. 提高张嘴阈值，或「张嘴持续」类触发（若版本无持续，可用第二次张嘴 / 点头叠加）  
2. 动作：  
   - `badge_leak` → **消失**  
   - `badge_sos` → **出现**  
   - `banner` → **出现**  
   - 剩余全部弹幕 → **出现**

### 事件 D（可选）：微笑 → 装可爱

1. **表情触发** → **微笑**  
2. `badge_cute` 出现 1~1.5 秒后消失  
3. `dm_09`（我是不是很好看）短暂飞入

## 4. 动画小技巧

- 弹幕：出现时加 **位移动画**（左→右或右→左）+ 轻微透明度  
- `thought`：加轻微 **上下浮动** 循环，更像「在想事情」  
- `banner`：出现时从上滑入，带一点弹性  
- 社死模式：可给画面叠一层红色滤镜 / 闪白（特效库里选轻量闪光）

## 5. 预览与提交

1. 右侧预览窗口：闭嘴应只见「表面淡定」；张嘴弹幕飞出  
2. **制作图标**：可用 `icon_effect.png`，或按预览裁剪  
3. 填写信息建议：  
   - 名称：`内心戏泄漏器`  
   - 简介：`张嘴就泄漏脑内弹幕，闭嘴秒变表面淡定。整蛊神器！`  
4. 自查无侵权文案后提交审核
