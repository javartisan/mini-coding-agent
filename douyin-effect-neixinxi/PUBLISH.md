# 抖音特效平台发布清单 · 内心戏泄漏器

> 云端 Agent **无法代你发布**：抖音只接受在 **像塑客户端内登录抖音账号后提交审核**，无公开上传 API。  
> 按下面步骤，约 10～20 分钟可完成提交。

## 前置条件（你必须具备）

1. Windows / macOS 电脑  
2. 已安装 [像塑桌面版](https://effect.douyin.com/)  
3. 用 **抖音账号** 登录像塑（需同意创作者协议）  
4. 本仓库 `douyin-effect-neixinxi/assets/` 素材（或下载 `release/内心戏泄漏器-像塑素材包.zip`）

## 提交信息（直接复制）

| 字段 | 填写内容 |
| --- | --- |
| 特效名称 | 内心戏泄漏器 |
| 特效简介 | 张嘴就泄漏脑内弹幕，闭嘴秒变表面淡定。整蛊神器，越说越社死！ |
| 触发提示（建议） | 张嘴说话，看脑内弹幕 |
| 图标 | 用 `assets/icon_effect.png`，或预览裁剪 162×162 PNG |
| 标签建议 | 搞笑、整蛊、互动、弹幕、社死 |

## 发布步骤

### 1. 在像塑里搭好特效

1. 新建 **2D / 人脸贴纸** 项目  
2. 导入 `assets/` 全部 PNG  
3. 按 [XIANGSU_GUIDE.md](./XIANGSU_GUIDE.md) 配置：  
   - 闭嘴 → `badge_calm`  
   - 张嘴 → 弹幕 + `badge_leak`  
   - 大张嘴 → `banner_warning` + `badge_sos`  
4. 预览确认三种状态都正常

### 2. 制作图标

1. 点右上角 **图标制作**  
2. 可选：本地上传 `icon_effect.png`（162×162，PNG）  
3. 建议同时做男生/女生图标（若版本支持）  
4. **确认应用**（不应用无法提交）

### 3. 提交审核

1. 点右上角 **提交特效**  
2. 粘贴上方名称、简介、触发提示  
3. 质量合规自查全部勾选  
4. 提交 → 等待 **1～2 天** 审核  
5. 审核通过后自动出现在抖音特效面板（搜索「内心戏泄漏器」）

## 合规自查（提交前勾一遍）

- [ ] 文案无人身攻击、色情、政治敏感  
- [ ] 贴纸为原创生成，无盗用品牌/明星素材  
- [ ] 触发逻辑可复现（张嘴/闭嘴）  
- [ ] 图标清晰、无第三方水印  
- [ ] 已用真机/预览测过人脸跟踪

## 审核通过后

- 抖音拍视频 → 特效搜索名称  
- 文案可配：`#内心戏泄漏器 #搞笑特效 #整蛊朋友`  
- 建议第一条视频用示范台词：  
  > 「我这个人特别真诚——」（张嘴刷屏）「……我没有内心戏。」
